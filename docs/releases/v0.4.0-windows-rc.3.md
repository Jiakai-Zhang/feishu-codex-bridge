# Feishu Codex Bridge v0.4.0-windows-rc.3

`v0.4.0-windows-rc.3` 是私有 Windows 多用户候选版。它保留 rc.2 的成员主动私聊、非空 Project 新建 Session、用户名片登记和 owner 远程 Session 权限控制，并补齐固定版本的全新安装与极简升级入口。

## 主要变化

- 新增 `docs/UPGRADE_WINDOWS_PROMPT.md`：正常健康路径由 Codex 完成预检、独立 PowerShell 事务升级、严格 Doctor 和升级后复核。
- updater 与 Doctor 通过后，用户只需完整重启 Desktop；不再要求用户复制或执行 PowerShell 命令。
- Windows 全新安装协议从公开单用户基线更新到私有 v0.4 本 tag，使用本机已登录的 GitHub CLI 访问固定版本。
- 全新安装协议补齐可选多用户 Project 根目录、Bot 主动 onboarding、用户名片登记、非空 Project 新建 Session 和 `/permissions` 验收；未明确要求同机多用户时仍保持 Owner-only，不额外询问。
- Full access、“替我审批”边界、DPAPI Secret、应用模板、浏览器备用 URL、直连/代理选择、Scheduled Task watchdog 和事务回滚要求没有放宽。

公开 `v0.3.2-windows-rc.4` 继续保留为旧的单用户公开基线；本 tag 需要 `ninmon/feishu-codex-bridge-private` 访问权。

## 升级

推荐把 README 中的 Windows 极简升级 Prompt 复制给当前电脑上的新 Codex 任务。协议内部最终使用：

```powershell
.\update.ps1 -Version v0.4.0-windows-rc.3 -Remote private
```

正常路径不需要用户手工运行这条命令。updater 保留 DPAPI Secret、本机配置、绑定、成员/Project 状态、Session 设置与权限、队列、附件、投递状态、relay state、bootstrap 和原代理模式；失败时自动回滚。
