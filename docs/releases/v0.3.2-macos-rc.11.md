# v0.3.2-macos-rc.11

`v0.3.2-macos-rc.11` 保留 rc.10 的固定安装协议，并修复新 Mac 实际部署中发现的 Keychain 沙盒与浏览器未弹出问题。它继续使用实验性的 Codex App Server WebSocket listener，不是稳定 release。

## 变更

- 安装 Prompt 在任何命令前强制一个人工停点：将当前 Codex 对话设为“完全访问（Full access）”，再开始只读预检。
- Keychain Secret 写入、读取、Bridge 启动与 Doctor 在密钥不可读时，明确提示检查当前对话 Full access，避免把沙盒拒绝误诊为 Secret 缺失。
- `configure-feishu-app.sh` 在尝试打开浏览器前，先输出一个最多两分钟有效、不含 App ID 的临时本机 loopback URL。
- 自动打开浏览器失败后，临时本机 URL 继续可用；超时后重跑脚本获得新 URL。
- Lark CLI 应用创建与 OAuth 停点始终向用户交付当次 verification URL，不输出 device code、原始 JSON、App ID、Secret 或 Token。

## 验收

```bash
npm run check
./doctor.sh --require-running --require-desktop-relay --require-desktop-attached
```

完整 Doctor 仍需在实际安装机上运行，并完成飞书与 Desktop 双向文本、入站图片/文件和出站原生附件验收。
