# Feishu Codex Bridge v0.4.0-windows-rc.5

`v0.4.0-windows-rc.5` 修复 RC4 在 Windows packaged Desktop 上的前台升级恢复问题。Session Relay 消息、权限、持久化格式、DPAPI 凭据和飞书应用配置均未改变。

## 修复内容

- Desktop 启动器现在通过 `Get-AppxPackage OpenAI.Codex` 与当前包的 `AppxManifest.xml` 动态解析真实 `ChatGPT.exe`，校验可执行文件仍位于包目录后，才向该进程注入已保存的 loopback 代理。
- packaged Desktop 不再因为使用 `-Proxy` 被一律拒绝；清单、包内路径或可执行文件无法验证时仍安全停止，也不会修改系统或用户全局代理。
- 前台升级器在启动时记录实际 Desktop 可执行路径。用户关闭可见窗口后，它只结束路径完全一致的残留 Desktop 进程，不按宽泛名称终止共享 App Server、其他 Codex CLI 或无关进程。
- 保留 RC4 的一次性 Interactive/Limited Scheduled Task、事务更新、代理模式保持、失败恢复、精确 tag 与严格 Doctor 验收。
