# v0.1.0-beta.1 — Codex Session Relay Beta

首个面向安装用户的 Windows / Codex 专用测试版。

## 主要能力

- 一个飞书群固定绑定一个 Codex 任务，支持 Project 任务和“独立”任务。
- 绑定群只有 owner 与当前 Bot 时，普通消息无需 `@Bot`。
- 飞书与 Codex Desktop 双向输入；同一活动 turn 的新消息默认成为原生 `turn/steer` 调整方向。
- `/queue` 可显式排队新 turn；另有 `/stop`、`/status`、`/model`、`/plan`、原生 `/goal` 生命周期与 `/delete`。
- 同步所有最终回答，不发送 reasoning 或工具过程；富文本中保留输入时间线、完成时间、用时和真实 token 使用量。
- 支持 Prompt 与最终回答中的本地图片，不暴露本机绝对路径或自动注入的文件包装文字。
- Bot 私聊 `/add` 可选择已有 Codex 任务并自动建群、命名、绑定和应用 `{主机名}-Codex` Feed 标签。
- `$feishu-session-bind` 用户 Skill 可从当前 Codex 任务直接请求创建或复用绑定群。
- 本机 supervisor、持久输入账本、Prompt FIFO 与投递发件箱支持重启和断线恢复。

## 安装体验

- 仓库根 `AGENTS.md` 与 `docs/INSTALL_AGENT.md` 组成 Codex 可执行的安装协议。
- `install.ps1` 固定依赖、发现已验证身份、生成本机配置、安装 Skill 并配置 Desktop 共享 App Server。
- `doctor.ps1` 检查运行时、依赖、Codex 能力、DPAPI secret、飞书身份/OAuth、Skill、环境变量和实时连接。
- `docs/FEISHU_APP_SETUP.md` 覆盖自建应用、Bot、权限、事件、版本发布和 Feed OAuth。

## Beta 限制

- 仅支持 Windows 与 Codex Desktop。
- 依赖 Codex App Server 的实验性 WebSocket 接口，Codex 更新后应先运行 `doctor.ps1`。
- 当前启动器不是 Windows Service；Windows 注销或重启后需再次运行 `start-bridge.ps1`。
- 仓库内保留的 Project Agent/多人协作实现不属于本版本的稳定发布合同。

完整步骤见 `docs/INSTALL.md`。
