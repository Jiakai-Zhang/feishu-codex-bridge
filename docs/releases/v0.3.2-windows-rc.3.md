# v0.3.2-windows-rc.3

`v0.3.2-windows-rc.3` 修复 Windows 新机部署中“替我审批”仍受沙盒限制、导致最终 Desktop relay 连接失败的问题。上游已将 `v0.3.2-windows-rc.2` 用于另一条候选分支，因此本安装修复顺延为 rc.3，避免同名 tag 指向不同内容。

## 变更

- Windows 安装 Prompt 在任何命令前强制一个人工停点：将当前 Codex 对话设为“完全访问（Full access）”，确认后才开始只读预检。
- 明确“替我审批（Approve for me）”只处理审批请求，不会解除文件系统、网络或 Windows 子进程沙盒边界。
- `AGENTS.md`、Windows 安装代理协议、安装指南、README 和飞书应用配置文档采用同一前置条件。
- `doctor.ps1` 与 Desktop relay 激活失败时给出 Full access 诊断提示，避免把沙盒限制误诊为 DPAPI、Scheduled Task、App Server 或 relay 配置损坏。
- 合入发布时最新的上游 `main`（`ca4ac65`），并在冲突解决中同时保留上游临时 Chat 动态 Session 与现有 active-writer relay handoff 行为。

## 验收

```powershell
npm ci
npm run check
.\install-smoke.ps1
.\doctor.ps1 -RequireRunning -RequireDesktopRelay
```

发布提交已通过跨平台 Node 检查；PowerShell smoke、严格 Doctor、真实飞书双向消息与附件仍需在 Windows 10/11 安装机上完成。
