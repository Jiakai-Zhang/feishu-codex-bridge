# v0.3.2-macos-rc.10

`v0.3.2-macos-rc.10` 保留 rc.9 的全部运行时修复，并简化公开的 macOS 安装入口。它继续使用实验性的 Codex App Server WebSocket listener，不是稳定 release。

## 变化

- README 的可复制安装 Prompt 现在只包含部署请求和一个固定版本协议链接。
- 完整读取、精确 tag、安全停点、应用命名、权限模板、直连/代理选择、初次绑定、Doctor 与双向附件验收要求全部位于链接内的 `docs/INSTALL_MACOS_PROMPT.md`。
- 链接协议新增“通过本链接调用安装代理”入口规则，明确要求 Codex 完整读取并直接执行“可复制 Prompt”，无需用户再次粘贴长指令。

## 运行时

运行代码与 rc.9 相同，包括：

- 代理切换后的 relay watchdog 驻留重试；
- 飞书 CLI/Doctor 直连校验与 Desktop 代理环境隔离；
- 一次飞书应用模板确认及脱敏校验；
- Keychain Secret、严格 Doctor、免私聊初次绑定和双向附件验收。
