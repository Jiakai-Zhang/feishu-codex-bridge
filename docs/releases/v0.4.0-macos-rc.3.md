# Feishu Codex Bridge v0.4.0-macos-rc.3

`v0.4.0-macos-rc.3` 是发布在私有镜像 `ninmon/feishu-codex-bridge-private` 的 macOS 多用户测试版本。它以 `v0.4.0-macos-rc.2` 为基线，让用户可以直接从 Bot 私聊的 `/add` 向导，在已经包含 Session 的 Project 中继续创建并绑定新 Session。

它仍依赖实验性 Codex App Server WebSocket listener，不是稳定 release。`package.json` 的 npm 版本不是安装版本依据，精确 Git tag 才是版本边界。

## 相比 rc.2

### 非空 Project 新建 Session

- 选择任意已有 Project 后，任务列表末尾都会显示“新建任务”；已有 Session 的编号保持不变。
- 输入任务名称后，Bridge 使用该 Project 已登记且通过访问控制的工作目录，通过共享 App Server 创建空 Session，然后立即创建专属飞书群并写入固定绑定。
- 新 Session 继承当前用户的目录边界和 owner 身份。普通成员不能在其他成员或 Owner 的 Project 中创建任务，Owner 对无归属旧 Project 的兼容访问保持不变。
- Project 为空时原有“重新扫描 / 返回 Project 列表 / 新建任务”流程不变；“独立”任务流程及其编号也不变。
- Codex Desktop 当前不会因为 Bridge 从外部创建 Session 而自动写入原生 Project 分组；Bridge 会在成功回复中保留这一说明，不修改 Codex 全局状态。

### rc.2 能力保留

- `/members add` 成功后，Bot 仍会主动私聊新成员并提示发送 `/add`。
- 成员目录、绑定、Session 设置、队列、附件、投递状态和 relay state 的持久化格式没有变化。

## 安装与升级

全新安装使用本 tag 中的 [macOS 安装 Prompt](../INSTALL_MACOS_PROMPT.md)。

现有安装若已配置精确的私有镜像远端，必须先完全退出 ChatGPT/Codex Desktop，再从独立 Terminal 运行：

```bash
./update.sh --version v0.4.0-macos-rc.3 --remote private
```

升级器保留 `bridge.config.json`、Keychain Secret、绑定、成员/Project 状态、Session 设置、临时 Chat、队列、账本、附件缓存、投递状态、Desktop relay state 与已保存代理模式。它不会改写 `origin`，也不会执行 `reset`、`clean` 或 `stash`。

## 验证

发布提交通过：

```bash
npm run check
```

本次本地结果为 366 项通过、1 项平台相关跳过、0 失败。真实 macOS 验收还应覆盖精确 tag、Bridge/Channel、App Server/relay/watchdog、Desktop attachment、原代理一致性、多用户根目录，以及在一个非空 Project 中从 `/add` 创建第二个 Session 并进入新绑定群。
