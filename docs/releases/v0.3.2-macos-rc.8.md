# v0.3.2-macos-rc.8

`v0.3.2-macos-rc.8` 是 Feishu Codex Bridge 的 macOS 安装流程候选版本，继续使用实验性的 Codex App Server WebSocket listener，不是稳定 release。

## 主要变化

- 新增 `configure-feishu-app.sh`：使用已认证的本机 Lark CLI 身份，通过不暴露 App ID 的 loopback 跳转打开飞书官方模板，一次确认 7 项应用/Bot 权限、4 项用户权限和 `im.message.receive_v1`。
- 新增 `verify-feishu-app.sh`：只输出脱敏状态，校验应用、Bot、用户 OAuth 和消息事件是否可用。
- `setup-channel-secret.sh` 可在生成 `bridge.config.json` 前运行，让 Channel App Secret 在创建应用后立即由用户存入 macOS Keychain。
- 新应用展示名称必须与运行 Codex Desktop 的 Mac 系统电脑名称完全一致。
- Desktop 重启前必须明确询问用户选择直连或无认证的本机 loopback 代理；不再默认替用户选择。
- 初次任务绑定直接使用安装后的 `$feishu-session-bind` 创建或复用专属群，不再要求先创建 Bot 私聊或发送 `/add`。
- 保留严格 Doctor、飞书双向消息、入站图片/文件和出站原生附件验收。

## 安装

从项目 [README](../../README.md#交给-codex-安装推荐) 复制 macOS 安装 Prompt，或直接读取 [macOS 完整安装协议](../INSTALL_MACOS_PROMPT.md)。

安装代理必须检出精确 tag `v0.3.2-macos-rc.8`。浏览器认证、应用模板确认、可能出现的管理员审批/应用发布、用户 OAuth、App Secret 安全输入和 Desktop 完整重启仍必须由用户本人确认。
