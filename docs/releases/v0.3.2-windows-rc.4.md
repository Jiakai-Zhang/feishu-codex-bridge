# v0.3.2-windows-rc.4

`v0.3.2-windows-rc.4` 取代 rc.3，保留 Windows Full access 安装修复，并合入上游 rc.2 已验证的跨平台路径修复。rc.3 的 macOS 检查通过，但发布后的 Windows CI 发现 POSIX 附件路径被错误转换为反斜杠；公开 tag 不移动，因此以 rc.4 修正。

## 变更

- Windows 安装 Prompt 在任何命令前强制当前 Codex 对话切换为“完全访问（Full access）”。
- 明确“替我审批（Approve for me）”只处理审批请求，不会解除文件系统、网络或 Windows 子进程沙盒边界。
- `doctor.ps1` 与 Desktop relay 激活失败时给出 Full access 诊断提示。
- POSIX 绝对附件路径始终使用 `path.posix.normalize`，不会在 Windows runner 上变成反斜杠路径。
- Windows symlink 测试使用 junction 类型，保持 Windows 与 POSIX runner 语义一致。
- 同步上游 `main`（`be75d65`），保留临时 Chat 动态 Session，并采用上游单 Session writer 冲突隔离与按需重试；一个被 Desktop/CLI 占用的 Session 不再拖垮其他绑定。

## 验收

```powershell
npm ci
npm run check
.\install-smoke.ps1
.\doctor.ps1 -RequireRunning -RequireDesktopRelay
```

发布前在 macOS 完成完整 Node 检查；上游 PR 的 Windows runner 必须全部通过后，rc.4 才作为推荐固定安装版。真实飞书双向消息与附件仍需在 Windows 10/11 安装机验收。
